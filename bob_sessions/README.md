# Bob sessions (REQUIRED for submission)

Every Bob 2.0 session used to build Incident2Fix is documented here.

## How to record a session
1. Run the pipeline stage (or any Bob-assisted work).
2. Save the session summary: `bob -p "..." > bob-sessions/<date>-<stage>.md`
   (or screenshot the Bob IDE chat and save the PNG here).
3. Fill in the template below for each session file.
