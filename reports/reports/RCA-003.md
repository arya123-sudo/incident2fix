# RCA-003: Inventory anomaly — negative reservation inflated stock

**Incident ID:** INCIDENT-003
**Triage Report:** TRIAGE-003
**Date:** 2026-09-18
**Severity:** SEV-3
**Confidence:** High

---

## Verdict

`reserve_stock()` applies no validation on the `qty` argument before mutating `STOCK`; a negative `qty` causes `STOCK[item] -= qty` to evaluate as subtraction of a negative number (i.e. addition), silently inflating stock rather than reducing it.

---

## Defect Location

`demo-app/app/inventory.py:8`

---

## Mechanism

[`reserve_stock()`](demo-app/app/inventory.py:6) performs the in-place subtraction `STOCK[item] -= qty` with no guard on the sign of `qty`. When `qty` is negative (e.g. `-5`), Python evaluates `100 -= -5` as `100 + 5 = 105`, increasing the stock level. The function returns the new (inflated) value and HTTP 200 with no indication of the problem. The [`/reserve` handler in `main.py:28`](demo-app/app/main.py:28) casts `body["qty"]` to `int` but performs no range check before the call, so the invalid input reaches the function unchallenged.

---

## Evidence

```python
# demo-app/app/inventory.py  (lines 6–9)
def reserve_stock(item: str, qty: int) -> int:
    """Reserve qty units of item. Returns remaining stock."""
    STOCK[item] -= qty   # ← no validation; negative qty inflates stock
    return STOCK[item]
```

Execution trace for `reserve_stock("widget", -5)`:
- `STOCK["widget"]` is `100`
- `STOCK["widget"] -= -5`  →  `100 - (-5)`  →  `105`
- Returns `105`  (stock inflated, not reduced)
