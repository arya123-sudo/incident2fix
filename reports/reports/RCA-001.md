# RCA-001: Checkout returns HTTP 500 for EUR currency

**Incident ID:** INCIDENT-001
**Triage Report:** TRIAGE-001
**Date:** 2026-09-20
**Severity:** SEV-2
**Confidence:** High

---

## Verdict

`currency.convert()` performs a bare dictionary key lookup (`SUPPORTED_CURRENCIES[code]`) with no fallback; passing any currency code absent from the dict (e.g. `"EUR"`) raises an unhandled `KeyError` that propagates to the `/checkout` handler and is returned as HTTP 500.

---

## Defect Location

`demo-app/app/currency.py:12`

---

## Mechanism

[`SUPPORTED_CURRENCIES`](demo-app/app/currency.py:3) is a hard-coded dict containing only `"USD"`, `"INR"`, and `"GBP"`. [`convert()`](demo-app/app/currency.py:10) accesses it with `SUPPORTED_CURRENCIES[code]` — a bare subscript that raises `KeyError` for any missing key. The exception is not caught in [`orders.checkout()`](demo-app/app/orders.py:13), which calls `currency.convert()` directly, so it propagates to the [`/checkout` handler](demo-app/app/main.py:14). That handler's broad `except Exception` clause catches it and returns `{"error": "'EUR'"}` with HTTP 500.

---

## Evidence

```python
# demo-app/app/currency.py  (lines 3–12)
SUPPORTED_CURRENCIES: dict[str, float] = {
    "USD": 1.0,
    "INR": 83.2,
    "GBP": 0.79,
}

def convert(amount: float, code: str) -> float:
    """Convert an amount from USD into the target currency."""
    return amount * SUPPORTED_CURRENCIES[code]   # ← bare lookup; raises KeyError for 'EUR'
```

```
main.py:15  orders.checkout(body)
  orders.py:13  currency.convert(discounted_total, order["currency"])
    currency.py:12  SUPPORTED_CURRENCIES["EUR"]   ← KeyError: 'EUR'
```
