# FIX-003: Inventory anomaly — negative reservation inflated stock

**Incident ID:** INCIDENT-003
**RCA Report:** RCA-003
**Date:** 2026-09-26
**Severity:** SEV-3
**Status:** ✅ Fix applied and verified

---

## Summary

Added a guard at the top of `reserve_stock()` that raises `ValueError` for any `qty` that is zero or negative, before any mutation of `STOCK` occurs. Positive inputs proceed unchanged.

---

## Diff

```diff
--- demo-app/app/inventory.py (before)
+++ demo-app/app/inventory.py (after)
@@ -6,4 +6,6 @@
 def reserve_stock(item: str, qty: int) -> int:
     """Reserve qty units of item. Returns remaining stock."""
+    if qty <= 0:
+        raise ValueError(f"qty must be positive, got {qty!r}")
     STOCK[item] -= qty
     return STOCK[item]
```
