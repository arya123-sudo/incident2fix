# FIX-002: Discount code "save10" silently applies no discount

**Incident ID:** INCIDENT-002
**RCA Report:** RCA-002
**Date:** 2026-09-26
**Severity:** SEV-3
**Status:** ✅ Fix applied and verified

## Summary

Normalized the user-supplied discount code to uppercase before the dictionary lookup. Any case variant (`"save10"`, `"Save10"`, `"SAVE10"`) now correctly matches the uppercase key. `None` is passed through unchanged (still returns 0 discount).

---
