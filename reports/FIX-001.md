# FIX-001: Checkout returns HTTP 500 for EUR currency

**Incident ID:** INCIDENT-001
**RCA Report:** RCA-001
**Date:** 2026-09-26
**Severity:** SEV-2
**Status:** ✅ Fix applied and verified

---

## Summary

Replaced the bare dictionary subscript `SUPPORTED_CURRENCIES[code]` with `.get()` plus an explicit `ValueError` for unknown codes. The `/checkout` handler now receives a typed, descriptive error instead of a raw `KeyError`.

---

## Diff

```diff
--- demo-app/app/currency.py (before)
+++ demo-app/app/currency.py (after)
@@ -10,3 +10,6 @@
 def convert(amount: float, code: str) -> float:
     """Convert an amount from USD into the target currency."""
-    return amount * SUPPORTED_CURRENCIES[code]
+    rate = SUPPORTED_CURRENCIES.get(code)
+    if rate is None:
+        raise ValueError(f"Unsupported currency: {code!r}")
+    return amount * rate
```

**File changed:** `demo-app/app/currency.py:12`
